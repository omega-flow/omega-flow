# API Reference

## Packages

### @omega-flow/engine

The core workflow engine that executes workflows, manages state, and handles events.

### @omega-flow/types

TypeScript types and JSON Schema validation for workflows, events, and context.

## Key Classes

### WorkflowModel

Manages workflow execution lifecycle.

```typescript
import { WorkflowModel } from '@omega-flow/engine'
```

### NodeModel

Base class for all node types.

```typescript
import { NodeModel } from '@omega-flow/engine'
```
